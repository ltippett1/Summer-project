# Flappy Bird Summer Project

This is a flappy bird style game which I created using HTML, CSS and JavaScript.

Users can control the bird using spacebar and they need to fly through the pipes without colliding with the option to collect coins to gain extra points.

## Features
- Three Difficulty Levels (Easy, Medium and Hard)
- Different pipe gaps for each difficulty
- Coins that appear inside the gaps between the pipes and increase players score if collected
- Different scoring values based on difficulty
- High scores saved into local storage
- High scores are saved separate based on difficulty
- Game Over screen
- Restart option
- Can change difficulty when game is over
- Space bar, Arrow Up and X can be used to make the bird jump

## How to Play
1. Open the game
2. Choose difficulty
3. Press either Space bar, Arrow Up and X can be used to make the bird jump
4. Keep bird in air by making it jump
5. Fly through pipe gaps
6. Collect coins to increase score
7. Avoid hitting pipes or bottom of the screen
8. When game end you can either restart or change difficulty

## Technologies Used
- HTML
- CSS
- JavaScript
